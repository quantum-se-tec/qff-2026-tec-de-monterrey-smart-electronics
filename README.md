# Qiskit Fall Fest 2026 @ Tecnológico de Monterrey – Smart Electronics

Website for the Qiskit Fall Fest 2026 event hosted at Tecnológico de Monterrey – Campus Monterrey in Monterrey, Nuevo León, México.

## Event

- Dates: November 3–7, 2026
- Workshop hours: 11:00 AM–2:00 PM (CST, UTC−6)
- Format: In person
- Location: Tecnológico de Monterrey – Campus Monterrey
- Participation: Free, registration required

The event combines quantum computing fundamentals, guided theory, practical examples, hands-on work with Qiskit, an IBM Quantum guest session, a team-based hackathon, and a final showcase.

## Organizing community

The event is organized through Smart Electronics, IEEE Communications Society, IEEE-Eta Kappa Nu (IEEE-HKN), Quantum Computing Club (QCC), and IEEE Student Branch. Supporting organizations are represented on the website.

## Repository

- `index.html` contains the website structure and content.
- `styles.css` contains the website presentation and responsive layout.
- `assets/` contains static website assets.
